Revival Church Live

Phone streaming app for Revival Church Mumbai (Android). Version 0.3.1, test build.

Download for Android (33.1 MB)
  1. Open this page on the Samsung phone and tap Download.
  2. Open the downloaded file and allow installing from this source.
  3. If the phone says it does not recognise the app, choose to install anyway.
  4. Open the app and allow the camera, microphone and notifications.

If an older test build is already on the phone, uninstall it first. Test builds do not install over each other, and saved stream keys are removed with the old build.

Stream keys are pasted on the phone and stay on the phone. This is a test build: try it on an unlisted stream before a service.
