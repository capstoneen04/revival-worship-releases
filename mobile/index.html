Revival Church Live

Phone streaming app for Revival Church Mumbai (Android). Version 0.4.1, signed with the church key.

Download for Android (33.1 MB)
  1. Open this page on the Samsung phone and tap Download.
  2. Open the downloaded file and allow installing from this source.
  3. If the phone says it does not recognise the app, choose to install anyway.
  4. Open the app and allow the camera, microphone and notifications.

Once only: if 0.3.2 or an older test build is on the phone, uninstall it first (it has a test key). Paste the stream keys again after installing. From 0.4.0 on, the app updates itself and keeps keys, songs and settings.

Previous version, if 0.4.1 gives trouble: 0.4.0. Stream keys are pasted on the phone and stay on the phone.
