# Revival Worship — downloads & updates

Revival Church Mumbai's worship and live-stream app (songbook, projector, Bible, OBS and ATEM production).

## First install
Download the installer from **[Releases](../../releases/latest)**:
- **Mac (Apple silicon, M1–M4):** `Revival-Worship-<version>-mac-arm64.zip` → unzip in Finder → move *Revival Worship* to Applications → open. If macOS blocks it: right-click → Open, or System Settings → Privacy & Security → Open Anyway.
- **Windows 10/11 (64-bit):** `Revival-Worship-Setup-<version>-win-x64.exe` → if Windows shows "protected your PC": More info → Run anyway.

On first start the app asks once for the **church library password** (ask the media team) to unlock the songs and the Hindi Bible.

## Updates
After the first install the app updates itself: **Settings → Updates** (checks every few hours, installs when you restart, never during a stream).
This repository holds only the update files (`latest.json`, `files/`). The song library is locked; members' details are never published here.

## Phone songbook (Android / iPhone)
Open **https://capstoneen04.github.io/revival-worship-releases/songbook/** in Chrome (Android) or Safari (iPhone).
Enter the church library password once — the songs are unlocked on the phone and then work **offline**.
- Android: menu **⋮ → Install app** (or *Add to Home screen*). iPhone: Share → **Add to Home Screen**.
- New songs from the media team arrive by themselves when the phone is online.
